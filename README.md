# Мини-шахматы 5×5: человек против ИИ (Minimax)

Лабораторная работа по игровому ИИ: искусственный игрок, выбирающий ход
алгоритмом **Minimax с альфа-бета отсечением**. Игра — упрощённые шахматы
на доске 5×5 (король, ладьи, пешки), платформа — **Unity 6**, вся графика
и интерфейс генерируются кодом, внешние ассеты не нужны.

> Отчёт по работе (описание игры, алгоритма, оценочной функции, пример хода
> ИИ, обоснование глубины поиска) — в файле [REPORT.md](REPORT.md).

## Запуск

1. Установите **Unity 6000.0.70f1** (Unity 6) через Unity Hub.
2. Unity Hub → **Add** → выберите папку `AI_lab_002` (лежит в этом репозитории).
3. Откройте проект и дождитесь импорта.
4. Откройте сцену `Assets/Scenes/SampleScene` (в ней есть объект **Game** со
   скриптом `GameLauncher`) и нажмите **Play**.

Сборка исполняемого файла: **File → Build Settings** — сцена уже добавлена в
список, выберите платформу и нажмите Build.

## Как играть

- **Ход**: клик по своей фигуре — подсветятся её допустимые ходы
  (зелёные точки — тихие ходы, красные кольца — взятия), затем клик по цели.
- **Новая игра: белые / чёрные** — начать партию за выбранную сторону
  (играя чёрными, ходите вторым; доска разворачивается).
- **Отменить ход** — откат к вашему предыдущему ходу.
- **Глубина ИИ: 2 / 3 / 4 / 5** — глубина поиска Minimax в полуходах
  (по умолчанию 4). Чем больше, тем сильнее и «дольше думает» ИИ.
- Панель слева внизу показывает статистику последнего поиска ИИ: сколько
  позиций просмотрено, время, выбранный ход и оценка.

Подсветки на доске: жёлтая клетка — выбранная фигура, жёлтые поля — последний
ход, красное поле — король под шахом.

## Правила игры

- Доска 5×5. Начальная позиция (белые снизу):

  ```
  |r|.|k|.|r|   чёрные: ладья a5, король c5, ладья e5
  |p|p|p|p|p|
  |.|.|.|.|.|
  |P|P|P|P|P|
  |R|.|K|.|R|   белые: ладья a1, король c1, ладья e1
  ```

- Фигуры: **король** (ходит на 1 клетку в любую сторону), **ладья**
  (по вертикали и горизонтали), **пешка** (на 1 клетку вперёд, бьёт по
  диагонали вперёд).
- Без рокировки, взятия на проходе и двойного хода пешки.
- **Превращение**: пешка, дошедшая до последней горизонтали, становится
  **ладьёй** (других фигур в игре нет).
- **Победа** — мат королю соперника. **Ничья** — пат, 50 ходов без взятий и
  ходов пешками, троекратное повторение позиции или два оставшихся короля.
- Белые ходят первыми.

## Структура проекта

```
AI_lab_002/               проект Unity 6 (2D URP)
  Assets/Scenes/          сцена SampleScene (объект Game)
  Assets/Scripts/Core/    игровое ядро — чистый C#, без зависимостей от Unity:
    GameState.cs            структура игрового состояния + MakeMove/UndoMove
    Move.cs                 описание хода и нотация (a2-a3, b4xa3, e2-e1=R)
    MoveGenerator.cs        допустимые ходы, шах, мат/пат, perft
    Evaluator.cs            оценочная функция позиции
    MinimaxAI.cs            Minimax + альфа-бета + сортировка ходов
  Assets/Scripts/Game/    Unity-слой:
    GameLauncher.cs         контроллер партии «человек против ИИ»
    BoardView.cs            доска, фигуры, подсветки, анимации
    GameUI.cs               интерфейс (uGUI, создаётся кодом)
    PieceArt.cs             процедурная генерация спрайтов фигур
ConsoleTests/             консольные тесты ядра (dotnet, общий код с Unity)
REPORT.md                 отчёт по лабораторной работе
```

## Консольные тесты

Игровое ядро (`Assets/Scripts/Core`) не зависит от Unity, поэтому покрыто
обычными консольными тестами (нужен .NET SDK):

```
dotnet run --project ConsoleTests
```

Проверяются: генерация ходов (perft 9 → 84 → 802 → 7512), полный откат
состояния, инварианты случайных партий, мат в 1 ход, пат, отказ от
«отравленной» пешки, партии ИИ против ИИ.
